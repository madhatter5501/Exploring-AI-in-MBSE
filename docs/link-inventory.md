## Important reading rule

- **Retrieved** is an access result, not a verified claim of product capability.
- **Official source indexed** means primary-source text was found through web search but not always retrieved directly in the audit session.
- **Public repository** means the author's own repository was checked; it is not an independent source.
- **Sign-in reached; import untested** means Holarch is accessible but authenticated actions were not verified.
- **Site configuration (not published)** is retained only for GitHub Pages setup; it should not be advertised as a working public URL yet.
